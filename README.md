# ✈️ British Airways PTFS — Website

> **Protótipo do site oficial da British Airways | PTFS | [BR🇧🇷]**

Um protótipo de website desenvolvido para a nossa companhia aérea de **RP no PTFS**, com foco na apresentação de materiais, identidade visual e conteúdos da companhia.

O projeto busca criar uma experiência moderna, elegante e responsiva, inspirada na estética de websites de aviação contemporâneos.

---

## 🌐 Sobre o projeto

Este repositório contém a versão inicial e experimental do website da companhia.

O objetivo principal é construir a estrutura visual do site antes da implementação dos materiais oficiais.

### Atualmente, o projeto inclui:

- 🏠 Página inicial
- 📁 Seção de materiais
- 🖼️ Galeria visual
- ⭐ Área de destaques
- ✈️ Conteúdo relacionado à companhia
- 📱 Design responsivo
- 🎨 Estrutura preparada para a identidade visual oficial

> **Nota:** As imagens utilizadas no protótipo são representadas por placeholders e serão substituídas pelos materiais oficiais posteriormente.

---

## 🎨 Design

O projeto foi desenvolvido com foco em uma estética:

- Moderna
- Minimalista
- Profissional
- Elegante
- Tecnológica
- Inspirada no setor de aviação

A interface foi pensada para funcionar tanto em **dispositivos móveis quanto em computadores**.

---

## 🛠️ Tecnologias

O protótipo utiliza tecnologias web simples e leves:

- **HTML5**
- **CSS3**
- **JavaScript**

A estrutura foi mantida propositalmente simples para facilitar futuras alterações e atualizações.
